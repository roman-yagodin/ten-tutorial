My Tomb Engine Tutorial workout.

## Development environment setup

1. Download and install Tomb Engine from https://tombengine.com
2. Create new "Tomb Engine" type project using TombIDE
3. Clone ten-tutorial git repository locally
4. Copy `Assets`, `Engine`, `Sounds` folders and `PLAY.exe` from newly created project to the ten-tutorial folder
5. Open ten-tutorial project from TombIDE
